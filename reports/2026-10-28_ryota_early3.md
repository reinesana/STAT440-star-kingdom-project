## 方法

材質・地表・0.5年刻みの管齢から漏水確率を推定し、近い管齢の履歴を平滑化する。
古い年の履歴には1年あたり0.85の重みを付ける。平滑化幅と履歴の重みは
2024・2025年の時系列検証で選び、2026年を設定選択に使わず確認した。
最終提出用モデルは2026年までの履歴で学習。

2027〜2029年は「残りの初期3年間で新たに防げる予想漏水損失／工事費」を使い、
単独円と最大6本をまとめる節約候補から選ぶ。交換対象が重なる候補は、円を選ぶたびに
残存リスクと費用を更新する。大きくまとめる効率が低ければ単独円を選ぶ。
後半は最大3本の設計グループを基本とする。半径の単調減少は強制しておらず、
実際の初期3年は短い高リスク管の単独交換が多く、半径中央値は3.86→5.24→6.43だった。

2026年の危険度上位10%による漏水捕捉率は旧モデル28.28%、新モデル49.57%。
ただし確率の平均は観測値より低く、log lossは改善していない。
旧・新モデル、ハザード0.5・1・2倍、各30回の共通乱数試算を保存した。
標準条件での初期3年修理費は旧モデルで3.23%、新モデルで8.25%低下。
これらの試算と上記public表示スコアを混同しない。

## 共通ルールとの照合で判明した留保

費用式は `2026-10-26-area-exponent`。共有リポジトリの `data/pipes.csv` と
`data/train.csv` は、この実験の入力ハッシュと一致した。
提出済みCSVはバイト単位で保存し、公式表示結果のファイルを作り直していない。

**全未交換鉄管のカバーは満たすが、共有検証の「全original ironへの幾何学的カバー」には不合格。**
元の実験は歴史的漏水管を交換済みとみなして円の生成対象から除いた。
共有検証ではその管にも円が必要なため、元の厳密な幾何学チェックを実行して失敗を記録し、
未交換鉄管だけを対象にした予算・完了検証は別の結果として明示する。
この記録を全ルール適合やprivate評価保証として扱わない。

共通シミュレーターによる未来漏水ゼロの工事費は、元の独立実装と一致。
全期間の漏水評価には、独立実装が工事完了後も漏水を計上する点などの差があるため、
共通シミュレーターで全てのモンテカルロ比較を再現したとは主張しない。

Google Docは読み取りを試みたが、このGitHub統合時は取得できなかった。
今回の統合では新しいモデル実験や再学習はせず、保存済み結果の追加と共通検証を行った。

## 再実行

リポジトリ直下の `data/` を自動参照する。実験フォルダへの生データ複製は不要。
前回の実験コードから変えたのは入力パスのフォールバックで、提出CSVは変更していない。

```sh
cd submissions/2026-10-28_ryota_early3
python -m unittest discover -v
python verify_early_outputs.py
python validate_shared.py
# 以下は保存されたローカル結果を再生成する場合だけ実行する。
python early_three_years.py --sims 30
```

再生成するとこのフォルダ内の実験出力を上書きするため、新しい実験では新しい日付の
フォルダを用意すること。共有検証にはリポジトリのrequirementsが必要。
