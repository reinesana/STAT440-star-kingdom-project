# train_predict_cost.csv：費用予測データとカラムの説明

## 目的と作成条件

配管が漏洩した場合に発生する `Cost` を、交換前の配管属性と漏洩日から推定するためのデータです。漏洩確率や漏洩する日を予測するデータではありません。また、漏洩前の計画交換費用と同じ金額になるとは限りません。

- 元データ：同じディレクトリの `train.csv` と `pipes.csv`。`Pipe ID` で1対1に結合。
- trainの14,113件は全件台帳に一致。元の項目に欠損がある6件（すべて敷設日欠損）を除外し、**14,107行・33列**を収録。
- 高額事例は正しい記録として保持。外れ値として削除・上限処理していません。
- `pipes.csv` は交換前台帳。漏洩後は全件ポリウレタンへ交換する前提ですが、交換後素材は入力に含めません。
- 地表は元の `Surface` 1種類。地表別の割合は作りません。
- 漏洩日・時刻・配管IDの順で並べています。期間は2019年1月6日～2026年12月31日。
- 元CSVは変更していません。

33列すべてを説明変数にするわけではありません。参照情報、目的変数、カテゴリの代替表現も含みます。通常のモデル入力は、文字列カテゴリ方式なら11項目、one-hot方式なら20項目です。

## 各カラムの意味と必要性

| カラム | 内容・計算方法 | 必要性・学習での役割 |
|---|---|---|
| `pipe_id` | 元のPipe ID | 他データとの結合、予測結果の追跡用。基本の説明変数にしない。 |
| `date` | 漏洩日（YYYY-MM-DD） | 管齢・季節・暦年の計算、年別の検証用。日付文字列をそのまま入力しない。 |
| `time` | 漏洩時刻（HH:MM） | 原記録の保全用。基本モデルでは使わず、将来シナリオにも時刻は要求しない。 |
| `cost` | 記録された費用 | **目的変数y**。説明変数Xには入れない。費用の通貨・内訳はCSV単独では確定できない。 |
| `lay_date` | 交換前配管の敷設日 | 管齢を計算する元情報。日付文字列自体は基本入力にしない。 |
| `material` | 交換前素材の文字列 | 素材による費用差を学習。カテゴリ対応モデルで使用。 |
| `surface` | 地表区分の文字列 | 地表による工事条件・費用差の候補。カテゴリ対応モデルで使用。 |
| `gps_x1` | 始点のx座標 | 元の形状情報の保全、長さ・中心の計算用。基本モデルでは中心座標を使用。 |
| `gps_x2` | 終点のx座標 | 同上。 |
| `gps_y1` | 始点のy座標 | 同上。 |
| `gps_y2` | 終点のy座標 | 同上。 |
| `pipe_length` | sqrt((x2-x1)^2+(y2-y1)^2) | 配管の規模を表す。端点を結ぶ直線距離であり、曲線の実延長ではない。 |
| `log1p_pipe_length` | ln(1+pipe_length) | 長さの非線形な関係を試す候補。元の長さと選択・比較する。 |
| `years_used_at_leak` | (漏洩日−敷設日の日数)/365.25 | 漏洩時点の管齢。日数は日付単位で計算し、小数年は丸めず保持。 |
| `log1p_years_used` | ln(1+years_used_at_leak) | 管齢と費用の非線形な関係を試す候補。 |
| `midpoint_x` | (x1+x2)/2 | 配管の代表位置。素材・地表だけでは表せない地域差の候補。 |
| `midpoint_y` | (y1+y2)/2 | 同上。 |
| `event_decimal_year` | 漏洩年＋その年の経過日数/その年の日数 | 年をまたぐ費用変化を表す候補。物価指数そのものではない。 |
| `season_sin` | sin(2π×その年の経過割合) | 季節性。年末と年始が近いことを表す。 |
| `season_cos` | cos(2π×その年の経過割合) | sinと組にして季節の位置を区別する。 |
| `material_code` | 素材の固定整数コード（下表） | カテゴリを整数で指定するモデル用。順位・距離の意味はない。 |
| `surface_code` | 地表の固定整数コード（下表） | 同上。 |
| `material_brass` | brassなら1、それ以外0 | 真鍮を表す素材フラグ。 |
| `material_cast_iron` | cast ironなら1、それ以外0 | 素材ラベルcast ironを表すフラグ。 |
| `material_copper` | copperなら1、それ以外0 | 銅を表す素材フラグ。 |
| `material_gray_iron` | gray ironなら1、それ以外0 | 素材ラベルgray ironを表すフラグ。 |
| `material_wrought_iron` | wrought ironなら1、それ以外0 | 錬鉄を表す素材フラグ。 |
| `surface_farmland` | farmlandなら1、それ以外0 | 農地を表す地表フラグ。 |
| `surface_grassland` | grasslandなら1、それ以外0 | 草地を表す地表フラグ。 |
| `surface_road` | roadなら1、それ以外0 | 道路を表す地表フラグ。 |
| `surface_structure` | structureなら1、それ以外0 | 構造物の地表区分を表すフラグ。 |
| `surface_swamp` | swampなら1、それ以外0 | 湿地を表す地表フラグ。 |
| `surface_water` | waterなら1、それ以外0 | 水域を表す地表フラグ。 |

座標・長さの単位は元データの座標単位です。既存EDAではメートルとして扱っていますが、CSVだけで単位を独立に確認できるわけではありません。季節と小数年は各暦年の365/366日を使用し、管齢の365.25とは区別しています。

## カテゴリコード

| material | material_code |
|---|---:|
| brass | 0 |
| cast iron | 1 |
| copper | 2 |
| gray iron | 3 |
| wrought iron | 4 |

| surface | surface_code |
|---|---:|
| farmland | 0 |
| grassland | 1 |
| road | 2 |
| structure | 3 |
| swamp | 4 |
| water | 5 |

素材・地表は順序のないカテゴリです。コードの大小や差に意味はありません。今回のtrainには交換前素材polyurethaneの事例がないため、対応するコードや全行0のフラグは設けていません。未知カテゴリを既存コードへ流用したり、全フラグ0にして黙って予測したりしないでください。未知カテゴリ・未観測条件の予測には追加検討が必要です。

## モデル別の列の選び方

共通の数値9列：

```python
numeric_features = [
    'pipe_length', 'log1p_pipe_length',
    'years_used_at_leak', 'log1p_years_used',
    'midpoint_x', 'midpoint_y',
    'event_decimal_year', 'season_sin', 'season_cos',
]
```

- **CatBoost等のカテゴリ対応モデル**：数値9列＋`material`, `surface`。2列をカテゴリとして指定する。
- **通常のRandom Forest等**：数値9列＋素材5列・地表6列のフラグ。計20列。
- **切片付き線形回帰**：one-hot方式から素材・地表それぞれ基準フラグを1列除くなどして完全共線性を避ける。基準カテゴリを記録する。
- **整数カテゴリ対応モデル**：数値9列＋`material_code`, `surface_code`。カテゴリ指定を必ず行う。

同じカテゴリについて文字列・コード・フラグを重ねて投入しません。`cost`、`pipe_id`等の参照列もXに混ぜません。log変換は精度向上を保証せず、特に決定木では元の値と同じ分割を表す場合があります。列は実験時に選択できます。

## 将来のシナリオで予測する場合

未漏洩の配管に想定漏洩日を与え、同じ定義で管齢・小数年・季節sin/cosを再計算します。素材、地表、長さ、中心位置と一緒にモデルへ入力し、「その日に漏れた場合の費用」を出します。過去の学習行の日時特徴量をコピーしません。将来の価格上昇は、暦年を与えただけで正しく外挿できるとは限らないため、必要なら価格シナリオを別に設定します。

## 検証方針

各年の比率を概ね保つ5-foldでMAE・RMSEの平均とばらつきを確認する方針です。将来年への汎化は、過去年で学習して後年を予測する検証を補助的に行います。特徴量選択・標準化などは各学習foldの情報だけで実施します。モデル学習・精度検証はまだ行っていません。

データ作成時には結合キーの一意性・全件一致、除外前後の件数、欠損なし、数値の有限性、管齢が非負であること、素材・地表の各フラグ群の合計が1であること、sin²+cos²=1、log変換の整合性を確認しています。
