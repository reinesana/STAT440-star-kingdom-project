# 過小評価を重く罰する金額回帰の比較（実行前固定）

- 目的変数は漏水が起きた場合の実際の修理金額。計画交換工事費ではない。漏水分類器は再学習しない。
- 損失は `0.5 * (actual-prediction)^2 * (k if prediction < actual else 1)`。k=1.0を対照、1.2〜3.0を0.2刻みで比較。予測値の事後一律乗算ではない。
- 有限の比較範囲はXGBoost、CatBoost、LightGBM、Random Forest、Extra Trees、Ridgeの6回帰モデル。三つのboostingは既存の各年の選択済み設定・特徴量を再利用。他は共通の保守的設定を固定する。既存の対数回帰やGamma回帰を全て再現する実験ではない。
- Boostingはカスタム勾配・ヘッセ行列、Ridgeは同じ非対称二乗損失の数値最適化。森林は残差に基づく重みを更新して最大4回再学習する近似法。反復ごとの学習損失を記録し最良反復を採用する。厳密解とは呼ばない。
- 2019〜前年までで学習、2023/2024/2025/2026を順次予測。全管への特徴量も各年1月1日より前の履歴だけ。特徴量のfuture mutationを検査する。
- 漏水予測は保存済みF168、施工円は全original iron一本ずつの中点円（半長径+1e-6m）、優先順位は重複更新付き `sum(翌年漏水確率 * 金額予測) / 現在工事費` に固定。
- 主指標は年間1,000万ドルで初年度に交換した管の、同年に実測された漏水修理費の回避率。漏水しなかった管にも予算を使った結果を含む。モデルの金額誤差や上位10%の金額捕捉率も補助指標とする。
- 2023〜2025平均の回避率で候補を一つ選択し、2026は候補選択から除外。各年の最良モデルを事後的に足し合わせない。2024/2025/2026について、前年までの結果だけで選ぶforward選択も記録する。
- 新しいk>1候補と、同一モデルのk=1、開発期間で選んだ最良k=1、既存CMS001を同じ施工条件で比較する。CMS001は過去年の予測が存在する2024〜2026のみ。欠損を2027の重みで埋めない。
- 2026で基準を上回らなくても結果を隠さず、候補CSVは探索用と明記する。2026を見て別の倍率へ変更しない。
- 全25年について、過去データだけで作る2種類の将来シナリオでも参考比較。実測の裏付けは初年度のみで、将来シナリオを公式スコアと呼ばない。
- 既存のG17等は最適化済み円を使うため、この共通円比較だけで提出全体の優位を断定しない。最終候補には共通円CSVと既存G17円を並べ替えたCSVを用意し、後者は別の感度分析と区別する。
- 書き出したCSVを再読込し、全original ironのカバー、修正済み工事費、年間予算と繰越、2051年までの完了を検査する。
- この依頼では提出ファイルを作成する。コンペへの送信、GitHub公開、共有Doc編集は実行しない。
- 2023〜2026は既存研究で利用された年であり、今回の2026の留保も完全未使用の最終テストではない。Public/Privateの改善は未確認。
